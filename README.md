# Cloud-Based Database (RDS) - Codtech Intern Task 2
By Sailaja | Python Cloud Database Project

## Overview
This project simulates AWS RDS operations. It shows how to connect to cloud database, create tables, insert, read, update, delete data like real AWS RDS MySQL.

## Features
1. Connect to Cloud RDS Instance
2. Create Table in RDS
3. Insert Data into RDS
4. Read/Query Data from RDS
5. Update & Delete Data
6. RDS Status Monitoring

## Technology
- Python 3
- SQLite3 (Simulates AWS RDS MySQL)
- Ready for real AWS RDS using boto3 + pymysql

python app.py
